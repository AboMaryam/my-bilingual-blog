Writing code that works is only the first step; writing code that humans can easily understand is what defines great software engineering.

## 1. Use Descriptive Variable Names

Avoid cryptic names like `d` or `temp` and use self-documenting names instead:

```javascript
// Unclear
const d = 7;

// Clear and expressive
const maxRetryDays = 7;
