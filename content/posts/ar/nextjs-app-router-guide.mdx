يعد نظام **App Router** نقلة نوعية في طريقة بناء تطبيقات الويب باستخدام React و Next.js، حيث يعتمد افتراضياً على مكونات الخادم (Server Components).

## لماذا نستخدم App Router؟

يوفر هذا النظام عدة مزايا جوهرية للمطورين:

- **سرعة تحميل فائقة:** يتم تجهيز HTML في الخادم وإرساله جاهزاً للمتصفح.
- **حجم حزمة JavaScript أصغر:** لا يتم إرسال مكتبات قراءة الملفات أو التنسيق إلى متصفح الزائر.
- **تحسين محركات البحث (SEO):** سهولة التحكم في Metadata لكل صفحة ديناميكياً.

## مثال عملي لجلب البيانات

يمكنك جلب البيانات مباشرة داخل المكوّن بدون الحاجة إلى `useEffect`:

```javascript
export default async function PostsPage() {
  const posts = await getAllPosts("ar");
  return (
    <section>
      <h1>جميع المقالات ({posts.length})</h1>
    </section>
  );
}
